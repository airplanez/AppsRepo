# AppsRepo

[English](README.md) | **한국어**

데스크톱 앱 배포용 저장소입니다.

> 이 저장소에는 **소스 코드가 없습니다**. 릴리스 빌드와 그 문서만 올립니다.

## 들어 있는 것

- **릴리스 배포물** — Linux · macOS · Windows 용으로 빌드한 패키지. [Releases](https://github.com/airplanez/AppsRepo/releases) 페이지에 올라갑니다.
- **앱 문서** — 앱마다 기능과 내려받기 · 설치 방법을 적은 Markdown 파일 하나.

## 앱

| 앱 | 설명 | 플랫폼 | 내려받기 |
| --- | --- | --- | --- |
| [RomClean](RomClean-ko.md) | MAME 롬 관리 · 롬셋 만들기 | Linux · macOS · Windows | [내려받기](https://github.com/airplanez/AppsRepo/releases/tag/RomClean) |

## 내려받기

1. 위 표의 **내려받기** 열에서 앱의 릴리스 페이지를 엽니다 (또는 [Releases](https://github.com/airplanez/AppsRepo/releases) 페이지).
2. 사용하는 OS · 버전의 파일을 내려받습니다 — 파일 이름은 `<앱>_v<버전>_<os>` 형식입니다.
3. 해당 앱 문서의 설치 방법을 따릅니다.

## 문의

버그 신고와 기능 제안은 [Issues](https://github.com/airplanez/AppsRepo/issues) 로 받습니다.
이 저장소에는 소스 코드가 없으므로 코드 변경 pull request 는 받지 않습니다.
