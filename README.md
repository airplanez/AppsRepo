# AppsRepo

**English** | [한국어](README-ko.md)

A distribution repository for desktop apps.

> This repository contains **no source code**. It only hosts release builds and their documentation.

## What's here

- **Release binaries** — prebuilt packages for Linux, macOS, and Windows, published on the [Releases](https://github.com/airplanez/AppsRepo/releases) page.
- **App documentation** — one Markdown file per app describing its features and how to download and install it.

## Download

1. Open the app's release page from the **Download** column of the table above (or the [Releases](https://github.com/airplanez/AppsRepo/releases) page).
2. Download the package for your platform and version — file names look like `<app>_v<version>_<os>`.
3. Follow the install steps in that app's document.

## Issues

Bug reports and feature requests are welcome via [Issues](https://github.com/airplanez/AppsRepo/issues).
